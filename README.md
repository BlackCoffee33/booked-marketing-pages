# BOOKED.marketing public publisher

This repository exists solely to host the approved public landing page on GitHub Pages.

Keep it intentionally small:

- `index.html` is the public site.
- `CNAME` binds the site to `booked.marketing`.
- Do not add unpublished intake flows, direct advisory-booking pages, client material, credentials, or internal implementation details.

The availability workflow checks the public homepage every six hours. A failed run means the site should be investigated before traffic is sent to it.
